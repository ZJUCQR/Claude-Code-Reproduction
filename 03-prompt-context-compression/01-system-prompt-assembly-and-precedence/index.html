    与压缩：组装与优先级（深潜审计版）

    核心论点

    组装层核心不是“拼字符串”，而是保持三件事同时成立：

    1. 提示来源优先级可解释；
    2. 静态/动态边界可缓存；
    3. 动态 section 失败可降级，不击穿主链。

    buildEffectiveSystemPrompt + getSystemPrompt + splitSysPromptPrefix 共同定义了这条契约。

    运行时状态所有权

    状态类别 所有者 关键机制 说明
    有效 prompt 优先级 systemPrompt.ts buildEffectiveSystemPrompt override > coordinator > agent/custom/default + append
    动态 section 缓存 systemPromptSections.ts + bootstrap state systemPromptSection / resolveSystemPromptSections 按 section name 缓存与复用
    全局边界标记 prompts.ts SYSTEM_PROMPT_DYNAMIC_BOUNDARY 静态前缀与动态尾部分段
    API cache scope 拆分 utils/api.ts splitSysPromptPrefix global/org/null cacheScope 路由

    端到端流程

    优先级选择

    // src/utils/systemPrompt.ts
export function buildEffectiveSystemPrompt(...) {
  if (overrideSystemPrompt) return asSystemPrompt([overrideSystemPrompt])

  if (feature('COORDINATOR_MODE') && ... && !mainThreadAgentDefinition) {
    return asSystemPrompt([getCoordinatorSystemPrompt(), ...append])
  }

  if (agentSystemPrompt && proactiveActive) {
    return asSystemPrompt([
      ...defaultSystemPrompt,
      `\n# Custom Agent Instructions\n${agentSystemPrompt}`,
      ...append,
    ])
  }

  return asSystemPrompt([
    ...(agentSystemPrompt ? [agentSystemPrompt] : customSystemPrompt ? [customSystemPrompt] : defaultSystemPrompt),
    ...append,
  ])
}

    前缀分段

    splitSysPromptPrefix 读取 boundary，将静态块赋 global scope，动态块走 null，降低 cache break 影响范围。

    守卫与决策矩阵

    Guard 条件 动作 结果
    override 短路 overrideSystemPrompt 存在 直接返回单段 prompt 跳过其余优先级链
    coordinator 模式 gate+env 开启且无 mainThreadAgent 使用 coordinator prompt 替代默认 prompt
    proactive agent 语义 proactive active 且有 agent prompt agent 指令 append 到 default 避免 replace 破坏自治基础 prompt
    cacheBreak section DANGEROUS_uncachedSystemPromptSection 每轮重算 明确接受 cache break
    boundary 存在 SYSTEM_PROMPT_DYNAMIC_BOUNDARY 在数组中 API 分离 static/dynamic block 静态块可 global cache
    boundary 缺失 未找到 marker 记录 missing boundary 事件 回退普通拼接策略

    失败、恢复与降级

    动态 失败降级

    单个 dynamic section 计算失败/返回 null 时，通过 filter 与缓存逻辑降级，不使 getSystemPrompt 整体不可用。

    边界缺失降级

    splitSysPromptPrefix 找不到 boundary 时回退到非边界分块路径，并记录 tengu_sysprompt_missing_boundary_marker。

    缓存污染恢复

    clearSystemPromptSections() 在 /clear 与 /compact 后执行，重置 section state 与 beta latches，防跨轮污染。

    不变量

    1. buildEffectiveSystemPrompt 返回值必须是可直接送 API 的 SystemPrompt。
    2. appendSystemPrompt 除 override 短路外始终在末尾。
    3. 动态 boundary 位置必须稳定（静态块后、动态块前）。
    4. section cache key 必须稳定且可显式清空。
    5. cacheBreak section 必须显式声明，不得隐式每轮重算。
    6. API 侧 boundary 解析失败必须可降级，不可中断请求。
    7. agent/coordinator/proactive 分支语义互斥且可解释。

    跨模块契约

    • 对 02/03（compact）：prompt 边界影响 cache 命中与 compact 重写成本，但不直接决定 compact 判定。
    • 对 04（cleanup）：compact 后必须清 section caches，保持新轮 prompt 构建一致性。
    • 对 01（query）：query 消费“已组装 prompt”，不反向干预组装优先级链。
    • 对 memory 模块：memory section 作为 dynamic section 注入，不应突破本页定义的缓存边界契约。
