    Structured / Print / Interactive 输出投影层（深潜审计版）

    1) Scope 与 Evidence Boundary

    本页只覆盖 09 模块里的 输出投影与非交互执行表面：

    • src/cli/print.ts 中 text/json/stream-json 输出路径；
    • StructuredIO / RemoteIO 选择与 stream guard；
    • headless runHeadlessStreaming 的消息收敛策略；
    • HelpV2 与命令建议系统如何投影 registry（不创建第二命令系统）。

    证据范围：

    • src/cli/print.ts:getStructuredIO
    • src/cli/print.ts:runHeadlessStreaming
    • src/cli/print.ts:getCanUseToolFn
    • src/components/HelpV2/HelpV2.tsx:HelpV2

    不覆盖：

    • argv fast-path 分流（见 01）；
    • Commander/preAction 启动屏障（见 02）；
    • registry/slash 主路由定义（见 03）；
    • bridge 管理平面状态机（见 05）。

    2) Core Thesis

    04 的核心不是“打印结果”，而是 同一消息语义在多输出协议上的稳定投影：

    1. text/json/stream-json 是协议投影，不是执行语义分叉；
    2. StructuredIO 与 RemoteIO 仅改变 I/O 通道，不改变 turn 语义；
    3. HelpV2/建议系统消费同一个 command facts；
    4. 非法组合（如 --print --output-format=stream-json 但无 --verbose）必须前置拒绝。

    3) Runtime State Ownership

    状态类别 所有者 关键函数 职责
    headless 输出主控态 print.ts print 主流程 + runHeadlessStreaming 非交互回合循环、消息筛选、最终输出
    IO 通道选择态 print.ts getStructuredIO sdkUrl 下 RemoteIO，否则 StructuredIO
    stream 协议守护态 print.ts stream-json guard 分支 防 stdout 杂音破坏 NDJSON
    权限提示桥接态 print.ts getCanUseToolFn stdio/MCP permission prompt 适配
    help UI 投影态 HelpV2.tsx + Commands.tsx HelpV2, Commands builtin/custom 命令列表展示与去重
    输入建议投影态 commandSuggestions.ts generateCommandSuggestions, applyCommandSuggestion slash 补全、别名匹配、中段 slash 高亮

    4) End-to-end Flow（print/structured 主链）

    4.1 print 前置参数与运行环境守卫

    print.ts 在创建 IO 前做参数互斥和 standalone 约束检查（如 --resume-session-at 依赖 --resume，--rewind-files 不能和 prompt 并用）。

    4.2 统一构建 structuredIO

    src/cli/print.ts:getStructuredIO：

    function getStructuredIO(inputPrompt, options): StructuredIO {
  let inputStream: AsyncIterable<string>
  if (typeof inputPrompt === 'string') {
    if (inputPrompt.trim() !== '') {
      inputStream = fromArray([
        jsonStringify({ type: 'user', message: { role: 'user', content: inputPrompt }, ... })
      ])
    } else {
      inputStream = fromArray([])
    }
  } else {
    inputStream = inputPrompt
  }

  return options.sdkUrl
    ? new RemoteIO(options.sdkUrl, inputStream, options.replayUserMessages)
    : new StructuredIO(inputStream, options.replayUserMessages)
}

    这保证字符串 prompt 与流式输入在下游统一为流语义。

    4.3 stream-json 输出先安装 stdout guard

    if (options.outputFormat === 'stream-json') {
  installStreamJsonStdoutGuard()
}

    目标是防止非 JSON stray stdout 污染 SDK 的逐行 JSON 解析。

    4.4 sandbox 与 hook 事件在结构化通道里显式投影

    • sandbox 不可用时给出错误/警告并可能终止；
    • stream-json + verbose 下注册 hook 事件并 structuredIO.write(...)。

    4.5 非法 output 组合前置拒绝

    if (options.outputFormat === 'stream-json' && !options.verbose) {
  process.stderr.write('Error: When using --print, --output-format=stream-json requires --verbose\n')
  gracefulShutdownSync(1)
  return
}

    4.6 runHeadlessStreaming 负责消息循环与归约

    主循环：

    for await (const message of runHeadlessStreaming(...)) {
  if (transformToStreamlined) {
    const transformed = transformToStreamlined(message)
    if (transformed) await structuredIO.write(transformed)
  } else if (options.outputFormat === 'stream-json' && options.verbose) {
    await structuredIO.write(message)
  }

  if (/* 非 control/system 流噪音 */) {
    if (needsFullArray) messages.push(message)
    lastMessage = message
  }
}

    然后按 outputFormat 输出：

    • json: 输出 lastMessage 或全数组（verbose）；
    • stream-json: 由上游循环持续写出；
    • text: 仅根据 result.subtype 显示终态文本。

    4.7 permission prompt 适配是懒解析

    getCanUseToolFn：

    • permissionPromptToolName === 'stdio' 时走 structuredIO.createCanUseTool；
    • 指定 MCP tool 时首次调用再从 getMcpTools() 解析，避免初始化时机竞态；
    • 找不到或 schema 不匹配时 stderr+shutdown+throw。

    5) Guard / Decision Matrix

    Guard 条件 行为 结果
    input contract guard --resume-session-at/--rewind-files 依赖不满足 stderr + shutdown 参数语义明确
    stream-json purity guard outputFormat=stream-json 安装 stdout guard 保证 NDJSON 可解析
    stream-json verbose guard stream-json 且非 verbose 快速失败 避免半结构化协议
    sandbox availability guard sandbox required 但不可用 直接失败；非 required 则警告 安全边界可见
    hook event stream guard stream-json + verbose hook 事件写入 structuredIO 生命周期可观测
    output reduction guard non-verbose text/json 仅保留 lastMessage 降低内存/噪音
    control-event filter guard control/session_state/task_* 等 不参与结果归约 终态稳定
    permission prompt tool guard 指定 MCP prompt tool 懒解析 + schema 校验 避免启动竞态与类型漂移
    IO backend guard 是否有 sdkUrl RemoteIO / StructuredIO 本地与远端协议统一

    6) Failure / Recovery / Degradation

    6.1 参数组合错误早失败

    --resume-session-at、--rewind-files、stream-json without verbose 都在主循环前终止，避免半启动状态。

    6.2 sandbox 不可用时区分 hard-fail 与 warning

    • required 模式：拒绝启动；
    • 非 required：提示“无沙箱运行”，继续执行。

    6.3 输出异常保持可消费终态

    text 模式根据 result.subtype 输出明确错误文本（如 structured output retries 超限）。

    6.4 permission prompt tool 不存在时显式退出

    MCP tool 名称不匹配或非 MCP tool 会立即报错并 shutdown，不静默回退到宽松权限。

    6.5 help / suggestion 退化路径

    • HelpV2 对 hidden/custom 空列表可展示空态；
    • suggestion 无匹配时返回空数组，不污染输入编辑流。

    7) Invariants

    1. getStructuredIO 必须把字符串 prompt 归一为流输入语义。
    2. stream-json 协议必须防 stdout 污染并保持结构化可解析。
    3. 输出模式切换只能改变表示层，不改变命令执行语义。
    4. runHeadlessStreaming 的结果归约必须排除 control/system 噪音事件。
    5. HelpV2 与建议系统必须消费同一命令事实源（commands）。
    6. permission prompt tool 解析失败必须显式报错，不可静默降级。

    8) Cross-module Contracts

    • 对 03：04 直接消费 registry 与 slash 结果，不定义命令存在性。
    • 对 02：04 假定 preAction/init 已完成，专注非交互输出协议。
    • 对 05：04 可承载 remote/bridge 事件输出，但不拥有 bridge 生命周期。
    • 对 Help 系统：src/commands/help/help.tsx:call 仅挂载 HelpV2，命令数据仍来自 runtime commands。

    9) Engineering Constraints / Evolution Guidance

    扩展 output mode 或建议/帮助 surface 时应检查：

    1. 是否复用 runHeadlessStreaming 统一消息流，而非新增独立执行循环；
    2. 是否定义了 output mode 的非法组合前置校验；
    3. 是否保持 control/system 事件过滤一致；
    4. 是否在 RemoteIO 与 StructuredIO 两侧都保持兼容；
    5. suggestion 排序/去重是否保持 getCommandName/alias/isHidden 语义一致。

    建议回归：

    • text/json/stream-json 三模式；
    • sdkUrl on/off（RemoteIO/StructuredIO）；
    • stream-json verbose 约束；
    • sandbox required/unavailable；
    • HelpV2 builtin/custom 列表与 hidden 去重；
    • suggestion 的 alias 匹配、mid-input slash、apply 行为。
