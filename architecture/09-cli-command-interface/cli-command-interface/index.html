CLI 命令行界面：启动分流、命令事实源与输出/桥接投影（深潜审计版）

1) Scope 与 Evidence Boundary

本页是 09 模块总览主文，覆盖 CLI 控制平面的 5 条主链：

  1. entrypoint fast-path 与 delayed import fallback；
  2. Commander 装配、preAction 初始化屏障与 action 编排；
  3. command registry 合流与 slash 路由分发；
  4. text/json/stream-json/help/suggestion 投影；
  5. plugin/install/remote-control 管理命令族与 bridge 启动 guard。

证据范围：

  • src/entrypoints/cli.tsx:main
  • src/main.tsx:main
  • src/main.tsx:run
  • src/commands.ts:getCommands
  • src/utils/processUserInput/processUserInput.ts:processUserInput
  • src/utils/processUserInput/processSlashCommand.tsx:processSlashCommand
  • src/cli/print.ts:getStructuredIO
  • src/cli/print.ts:runHeadlessStreaming
  • src/components/HelpV2/HelpV2.tsx:HelpV2
  • src/utils/suggestions/commandSuggestions.ts:generateCommandSuggestions
  • src/bridge/bridgeMain.ts:bridgeMain

不覆盖：

  • query/tool 主执行状态机（见 01）；
  • bridge 长连接恢复细节状态机（见 07）；
  • skills 内部 discovery/runtime 细节（见 08）。

2) Core Thesis

09 的本质不是“命令很多”，而是把同一 command/message 语义稳定投影到不同入口与输出协议。

  • 入口层（01/02）决定何时、以何成本进入 CLI；
  • registry 层（03）定义命令事实与可见性真相；
  • 输出层（04）只改表现协议，不改执行语义；
  • 管理层（05）给高副作用能力设置独立 guard。

一句话：09 是 CLI 控制面的一致性编排层。

3) Runtime State Ownership

状态类别 所有者 关键函数 职责
argv 分流态 entrypoints/cli.tsx main fast-path 命中与 full CLI fallback
启动屏障态 main.tsx main / run / preAction hook init/migration/sinks/setup 编排
命令事实态 commands.ts loadAllCommands / getCommands 多来源并轨 + availability/enabled 过滤
slash 路由态 processUserInput.ts + processSlashCommand.tsx processUserInput / processSlashCommand /cmd args 解析、unknown 恢复、type 分派
输出投影态 print.ts getStructuredIO / runHeadlessStreaming text/json/stream-json 终态收敛
help/建议投影态 HelpV2 + suggestions HelpV2 / generateCommandSuggestions 消费同一 commands facts
管理命令态 main.tsx + bridgeMain.ts run / bridgeMain plugin/install/remote-control 及 bridge 启动门槛

4) End-to-end Flow（09 总链）

  1. cli.tsx:main 先做顶层 argv 分流：命中快路径即返回；
  2. 未命中时 delayed import main.js，进入 main.tsx:run；
  3. preAction 先跑关键初始化，再进入 action；
  4. getCommands 合流 commands 并做 availability/enabled/filter；
  5. 用户输入经 slash gate 路由到 local/local-jsx/prompt/fork；
  6. runHeadlessStreaming 与 Help/Suggestions 将结果投影到不同 surface；
  7. 管理命令族（plugin/install/remote-control）在独立 guard 下调整运行环境。

5) Guard / Decision Matrix（跨子页汇总）

Guard 发生层 条件 行为 结果
entry fast-path guard 01 --version/bridge/bg/daemon 等 直接短路执行 降低启动成本
fallback import guard 01 未命中快路径 delayed import main.js 全量 CLI 可预测启动
preAction barrier guard 02 任意 action 前 统一 init/sinks/migrations 子命令初始化一致
availability/enabled guard 03 cmd 不满足可用/启用条件 过滤出 registry 命令面稳定
remote/bridge-safe guard 03 remote/bridge 输入 前置限制命令集 控制面安全
unknown/path-like slash guard 03 slash 未命中 unknown 提示或降级普通输入 恢复路径可用
stream-json purity guard 04 stream-json 模式 stdout guard + verbose约束 NDJSON 可解析
output reduction guard 04 non-verbose 仅保留 lastMessage 降噪与低内存
bridge startup guard 05 permission/trust/auth/baseUrl 明确 fail-stop 远程入口安全

6) Failure / Recovery / Degradation（跨子页）

  • fast-path 失败局部化，不污染 full CLI；
  • preAction 关键失败 fail-stop，后台同步任务 fail-open；
  • slash malformed/unknown/path-like 输入有恢复分支；
  • stream-json 非法组合前置拒绝，避免半结构协议；
  • bridge 启动失败显式退出，不静默降级为“看似可用”。

7) Invariants

  1. full CLI 路径下，preAction 必须先于 action。
  2. getCommands 是 slash/help/suggestions/skill consumers 的共享事实源。
  3. remote-safe / bridge-safe 过滤必须在执行前完成。
  4. output mode 只能改变表示层，不得改变执行语义。
  5. stream-json 必须保持结构化可解析（guard + verbose 约束）。
  6. 管理命令族必须维持独立安全门槛（trust/auth/baseUrl 等）。

8) Cross-module Contracts

  • 对 01：09 消费 query/tool 执行能力，不定义其内部状态机。
  • 对 05：09 只接入 MCP/bridge 的入口与可见性，不接管连接生命周期。
  • 对 06：09 触发 hooks 与 sinks，不拥有 hooks 执行引擎。
  • 对 08：09 与 skills 共享 command registry，禁止第二命令系统。
  • 对 07：09 做输出投影，07 保证流式恢复与 transport 语义。

9) Engineering Constraints / Evolution Guidance

扩展 09 时先问 5 个问题：

  1. 新逻辑应在 entry fast-path 还是 full CLI？
  2. 是否必须放 preAction，还是可异步 fail-open？
  3. 是否接入统一 getCommands 事实源？
  4. 是否破坏 slash 恢复语义或 output 协议纯度？
  5. 是否改变 remote/bridge 安全门槛（若是，是否有前置 guard）？

建议回归矩阵：

  • 01：version/bridge/bg/tmux-worktree/fallback；
  • 02：preAction 顺序 + worktree cwd 一致性；
  • 03：source merge + availability + malformed/unknown/path-like；
  • 04：text/json/stream-json + sdkUrl on/off + help/suggestions；
  • 05：plugin/install/remote-control + bridge trust/auth/baseUrl。
