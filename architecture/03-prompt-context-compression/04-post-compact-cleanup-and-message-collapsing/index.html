    Prompt 与压缩：压缩后清理与消息折叠（深潜审计版）

    1) Scope 与 Evidence Boundary

    本页覆盖 compact 执行后的“收尾与展示层收敛”，证据范围：

    • src/services/compact/postCompactCleanup.ts
    • src/services/compact/compact.ts（post-compact 构造与 hooks）
    • src/services/compact/compactWarningState.ts
    • src/services/compact/compactWarningHook.ts
    • src/utils/collapseReadSearch.ts
    • src/utils/collapseBackgroundBashNotifications.ts

    不覆盖：

    • compact 触发判定（见 02）；
    • micro/session-memory compact 内部执行（见 03）。

    2) Core Thesis

    压缩“成功”并不意味着流程结束；真正的稳定点在 post-compact cleanup：

    1. 清理会话级缓存与模块级状态；
    2. 重建 post-compact 附件上下文；
    3. 对展示层做可逆折叠，减少噪音；
    4. 保证下一轮 query 在干净且可继续的状态启动。

    3) Runtime State Ownership

    状态类别 所有者 关键函数/字段 说明
    cleanup 执行态 postCompactCleanup.ts runPostCompactCleanup(querySource?) compact 后核心清扫
    boundary+summary 构造态 compact.ts buildPostCompactMessages / createCompactBoundaryMessage 压后消息拓扑
    warning 抑制态 compactWarningState.ts store + suppress/clear 控制 compact warning 展示
    warning UI 订阅态 compactWarningHook.ts useCompactWarningSuppression React 层订阅
    read/search 折叠态 collapseReadSearch.ts collapseReadSearchGroups 连续读搜分组摘要
    bash 通知折叠态 collapseBackgroundBashNotifications.ts 聚合 completed 通知 减少噪音消息

    4) End-to-end Flow

    4.1 compact 后生成可继续上下文

    compactConversation 在 summary 产出后追加：

    • file/plan/skill/agent attachments；
    • deferred tools / agent listing / mcp instructions delta；
    • session start hooks 与 post-compact hooks。

    4.2 cleanup 入口

    // src/services/compact/postCompactCleanup.ts
export function runPostCompactCleanup(querySource?: QuerySource): void {
  const isMainThreadCompact =
    querySource === undefined ||
    querySource.startsWith('repl_main_thread') ||
    querySource === 'sdk'

  resetMicrocompactState()
  if (isMainThreadCompact) {
    getUserContext.cache.clear?.()
    resetGetMemoryFilesCache('compact')
  }
  clearSystemPromptSections()
  clearClassifierApprovals()
  clearSpeculativeChecks()
  clearSessionMessagesCache()
}

    4.3 展示层折叠

    • collapseReadSearchGroups 折叠连续 Read/Grep/Glob/部分 Bash 搜索读操作；
    • collapseBackgroundBashNotifications 在 fullscreen 且非 verbose 时聚合连续 completed 通知。

    5) Guard / Decision Matrix

    Guard 条件 动作 结果
    main-thread cleanup querySource undefined/repl_main_thread*/sdk 执行完整主线程清理 避免跨轮污染
    subagent cleanup querySource=agent:* 等 跳过主线程专属 reset 防主线程状态被误清
    context-collapse gate feature 开启且 main-thread compact resetContextCollapse() 清理 collapse 状态
    warning suppress compact 成功 suppressCompactWarning() 压后短期抑制误报
    warning clear 新 compact 尝试开始 clearCompactWarningSuppression() 恢复真实告警
    read/search 折叠 连续可折叠 tool_use/result 合并摘要组 保留可解释顺序
    bash 通知折叠 fullscreen && !verbose && 连续 completed bash 通知 合并为 N 条完成摘要 减少 UI 噪音

    6) Failure / Recovery / Degradation

    6.1 cleanup 失败降级

    cleanup 属于后处理；即使某些清理动作失败，也不应阻断 query 主链继续。

    6.2 subagent 防误清恢复

    isMainThreadCompact 分支确保 subagent compact 不重置 main-thread 共享模块状态，避免“远端压缩污染主会话”。

    6.3 折叠降级

    折叠仅在满足条件时启用；不满足（如 verbose）则原样透传，保证可调试性。

    6.4 warning 状态恢复

    warning suppression 只在 compact 成功后设定；下一次 compact 尝试开始时清空，避免长期隐藏真实告警。

    7) Invariants

    1. compact 后必须重置 microcompact 状态。
    2. subagent compact 不得清理 main-thread 关键缓存。
    3. system prompt sections 需在 compact 后清空，避免缓存陈旧。
    4. 展示层折叠不得修改执行语义，仅改变 UI 聚合。
    5. verbose 模式必须保留通知明细，不可强制聚合。
    6. post-compact 消息必须保留 boundary + summary + 必需附件。
    7. warning suppress/clear 必须成对出现，避免长期误抑制。

    8) Cross-module Contracts

    • 对 03（执行层）：执行层输出 compaction result；本页负责“让结果可持续运行”。
    • 对 01（query）：cleanup 完成后 query 可继续，不应重新解释 compact 事务细节。
    • 对 02（memory）：cleanup 会清理 memory 文件缓存，保证后续记忆读取与新状态一致。
    • 对 UI 层：collapse 是渲染优化，不是消息协议改写。

    9) Engineering Constraints / Evolution Guidance

    新增 cleanup 或折叠逻辑时必须验证：

    1. main-thread/subagent 分支是否正确；
    2. 是否引入不可逆展示变换；
    3. 是否影响 post-compact hooks 与附件重建顺序；
    4. 是否在 verbose/debug 路径仍保留可观测细节。

    建议回归：

    • main-thread compact 与 subagent compact 对比；
    • compact 后 systemPrompt/memory/userContext cache 清理；
    • fullscreen+verbose 组合下 bash 通知折叠行为；
    • collapseReadSearch 连续分组与断组规则。
