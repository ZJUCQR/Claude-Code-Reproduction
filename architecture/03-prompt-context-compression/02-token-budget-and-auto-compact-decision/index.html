Prompt 与压缩：Token 预算与自动压缩判定（深潜审计版）

1) Scope 与 Evidence Boundary

本页只覆盖“何时 compact / 何时续轮 / 何时停止”的决策层，证据范围：

  • src/services/compact/autoCompact.ts
  • src/query/tokenBudget.ts
  • src/query.ts（blocking、withheld、recover 分支）

不覆盖：

  • compact 执行细节（见 03）；
  • post-compact cleanup 与渲染折叠（见 04）。

2) Core Thesis

决策层的核心价值是把“上下文压力”收敛为可审计状态机，而不是临时 if/else：

  1. token 阈值统一计算；
  2. querySource 禁区明确阻断；
  3. autocompact 失败有熔断上限；
  4. recoverable API error 先 withheld 再恢复；
  5. token budget continuation 有退出条件。

3) Runtime State Ownership

状态类别 所有者 关键字段/函数 说明
阈值函数族 autoCompact.ts getEffectiveContextWindowSize / getAutoCompactThreshold / calculateTokenWarningState warning/error/blocking/auto 阈值
auto 开关状态 autoCompact.ts isAutoCompactEnabled env + user config 联合门控
auto 决策状态 autoCompact.ts shouldAutoCompact querySource/gate/threshold 统筹判断
连续失败状态 autoCompact.ts AutoCompactTrackingState.consecutiveFailures circuit breaker
budget 续轮状态 query/tokenBudget.ts BudgetTracker continuation/diminishing 评估
recover 过渡状态 query.ts transition reason（如 reactive_compact_retry） 恢复分支可审计

4) End-to-end Flow

4.1 自动压缩判定

// src/services/compact/autoCompact.ts
export async function shouldAutoCompact(messages, model, querySource, snipTokensFreed = 0) {
  if (querySource === 'session_memory' || querySource === 'compact') return false
  if (!isAutoCompactEnabled()) return false
  ... // reactive/context-collapse suppressions
  const tokenCount = tokenCountWithEstimation(messages) - snipTokensFreed
  const { isAboveAutoCompactThreshold } = calculateTokenWarningState(tokenCount, model)
  return isAboveAutoCompactThreshold
}

4.2 自动压缩执行入口（决策视角）

autoCompactIfNeeded 先做熔断判断，再判断 shouldCompact，再尝试 SM compact，最后 fallback full compact。

4.3 query 阻断与 recover

  • 先按 blocking limit 做硬阻断（在允许场景）；
  • streaming 阶段对 recoverable 错误执行 withheld；
  • 回合末按 413/media/max_output 分支 recover 或 surface。

4.4 token budget continuation

checkTokenBudget 在未达 completion threshold 且无明显收益衰减时触发续轮 meta message；达到 stop 条件则返回 completion event。

5) Guard / Decision Matrix

Guard 条件 动作 结果
recursion guard querySource in {session_memory, compact} shouldAutoCompact=false 防 fork deadlock
autocompact disabled env/settings 关闭 直接 false 仅手动 compact
reactive-only suppression tengu_cobalt_raccoon=true 禁止 proactive auto 由 reactive recover 接管
context-collapse suppression isContextCollapseEnabled() 禁止 proactive auto 防双系统竞争
hard blocking isAtBlockingLimit=true 且未被豁免 返回 prompt-too-long error reason=blocking_limit
auto failure breaker consecutiveFailures >= 3 跳过自动重试 抑制 API 风暴
413/media withheld recoverable error 命中 暂不输出错误 进入 recover 尝试
recover fail 尝试后仍失败 surface 错误并 return 明确终止
budget continue <90% 且非 diminishing 插入续轮消息并 continue token_budget_continuation
budget stop 达 stop 条件 completion event 正常结束

6) Failure / Recovery / Degradation

6.1 auto compact 失败恢复

SM compact 失败（null）不报错，直接 fallback legacy compact；legacy 失败则计入连续失败并可触发熔断。

6.2 withheld 恢复链

query.ts 对 PTL/media/max output 先 withheld；若 recover 成功则 continue，否则 surface + return，避免“可恢复错误”提前中断。

6.3 stop hooks 避让

当 lastMessage 为 API error 时跳过 stop hooks，防止 error->hook blocking->retry 螺旋。

6.4 budget 降级

budget 机制在 agentId 或 budget<=0 时直接 stop，不给主链添加额外负担。

7) Invariants

  1. token 判定口径必须统一到同一估算函数。
  2. 自动压缩不得作用于 session_memory 与 compact 来源。
  3. snipTokensFreed 必须参与判定抵扣。
  4. recoverable 错误必须先 withheld 再 recover/surface。
  5. 连续失败重试必须有上限。
  6. budget continuation 必须可退出（diminishing 或达标）。
  7. blocking 逻辑与 recover 逻辑不能互相饿死。

8) Cross-module Contracts

  • 对 03（执行层）：本页只决定“触发与否”，不定义具体 compact 消息重构方式。
  • 对 01（query loop）：决策输出是 transition/state 变化，必须可被主状态机消费。
  • 对 04（cleanup）：决策层触发 compact 后依赖 cleanup 收尾，但不内联 cleanup 细节。
  • 对 reactive/context-collapse： suppressions 必须与 recover 路径语义一致，防止 withhold 无恢复。

9) Engineering Constraints / Evolution Guidance

调整阈值或 gate 时必须验证：

  1. querySource 禁区是否完整；
  2. blocking 与 reactive recover 是否出现覆盖冲突；
  3. 熔断阈值是否能避免重复失败风暴；
  4. budget 续轮是否仍可及时停止。

建议回归：

  • session_memory / compact 来源；
  • reactive-only/context-collapse 开关组合；
  • 连续 compact 失败触发熔断；
  • withheld 413/media/max_output 的 recover/surface 双路径；
  • token budget continuation + diminishing returns 停止。
