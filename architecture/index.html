Claude Code 源码架构全景（src/ 全量覆盖）

本目录按 9 个核心能力模块组织对 src/ 的源码级审计文档，并提供覆盖证明文件：

  • 全量文件清单：coverage/src-file-manifest.csv
  • 模块归属映射：coverage/src-module-mapping.csv
  • 覆盖统计：coverage/coverage-summary.md
  • 未归类处置：coverage/uncategorized-resolutions.md

源码主链锚点（总览）

  • src/entrypoints/cli.tsx（CLI 启动分流与 fast-path）
  • src/main.tsx（Commander 装配与 preAction 初始化屏障）
  • src/query.ts（主 query loop 状态机）
  • src/services/tools/toolOrchestration.ts（工具批次编排与并发分流）
  • src/services/tools/toolExecution.ts（单工具执行、权限与错误语义）
  • src/services/mcp/client.ts（MCP 连接、发现与调用）
  • src/utils/hooks.ts（Hook 统一执行入口）
  • src/cli/structuredIO.ts（结构化协议 request-response 关联）
  • src/tools/SkillTool/SkillTool.ts（Skill 运行时与权限决策）
